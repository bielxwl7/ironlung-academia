# 🏋️ IronLung — Um projeto que transformou código em uma experiência completa

Nem todo projeto da faculdade termina quando o código funciona. Alguns projetos fazem você perceber o quanto ainda existe para aprender. **O IronLung foi um desses projetos.**

Desenvolvido em equipe com meus amigos **Danilo Marques e João Marcelo**, o IronLung é um projeto de website para uma academia voltada para atletas e alta performance.

A proposta era criar mais do que uma página simples: queríamos desenvolver uma experiência completa para o usuário, com diferentes seções e páginas, identidade visual própria e uma navegação que representasse a proposta da academia.

💻 **Tecnologias utilizadas:**

* HTML5
* CSS3
* Font Awesome
* Git/GitHub

Durante o desenvolvimento, trabalhamos na criação de diferentes páginas, incluindo **Home, Sobre, Contato, Treinos, Planos, Avaliação Física e modalidades esportivas**, além da construção da identidade visual do projeto.

### 📚 O que esse projeto me ensinou?

Mais do que aprender novas propriedades de HTML e CSS, esse projeto me ajudou a entender melhor como transformar uma ideia em um projeto estruturado.

Aprendi mais sobre:

🔹 Organização e estruturação de páginas web
🔹 Estilização e criação de interfaces com CSS
🔹 Organização de arquivos e componentes de um projeto
🔹 Desenvolvimento de uma identidade visual
🔹 Pensar na experiência de quem vai utilizar o site
🔹 Resolver problemas durante o desenvolvimento
🔹 Trabalhar com diferentes páginas mantendo uma identidade visual consistente

### 🤝 E trabalhar em equipe?

Essa foi uma das partes mais importantes do projeto.

Desenvolver algo em grupo significa aprender a **dividir responsabilidades, ouvir ideias diferentes, discutir soluções e encontrar um caminho em conjunto**.

Nem sempre as ideias são iguais e nem sempre tudo funciona de primeira. E justamente por isso o trabalho em equipe se torna uma experiência tão importante para quem está começando na área de tecnologia.

O resultado final não representa apenas algumas páginas em HTML e CSS. Ele representa **horas de estudo, testes, erros, correções, ideias e colaboração.**

🚀 **Esse projeto foi mais um passo na minha evolução dentro da tecnologia.**

Ainda tenho muito para aprender, mas cada projeto me mostra que conhecimento não vem apenas de estudar a teoria — vem também de **colocar a mão no código, enfrentar problemas e construir algo do zero.**

Agradeço ao **Danilo e ao João** pela parceria durante o desenvolvimento.

**Esse é apenas um dos primeiros projetos da minha trajetória na programação. E certamente não será o último.**
